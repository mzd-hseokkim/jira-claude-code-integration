## Implementation Plan

### 1. `CLAUDE.md` "PDCA Documents" 섹션 갱신 (현재 line 80-84)

현재 상태 (3개 항목):
```
- Plan: docs/plan/<TASK-ID>.plan.md
- Design: docs/design/<TASK-ID>.design.md
- Test Report: docs/test/<TASK-ID>.test-report.md
```

변경: Requirements 항목을 맨 앞에 추가하여 워크플로 순서(discover → plan → design → test) 반영. 4개 항목으로 확장.

추가할 라인 (시그니처 수준):
- `Requirements: docs/requirements/<slug>.requirements.md` — discover 단계 산출물

### 2. `CLAUDE.md` "Workflow Commands" 섹션 갱신 (현재 line 129-145)

현재 상태: `init` 부터 시작. `discover`, `create`, `auto`는 일부만 있거나 빠짐.

변경:
- `/jira-task discover [주제 | --lite | --from <파일>]` 항목 추가 — `init` 라인 위에 배치
- `/jira-task create [자연어 힌트 | --from-requirements <파일>]` 항목이 빠져 있다면 추가 (현재 빠짐 확인됨) — `discover` 다음에 배치

### 3. 워크플로 그래프 / 단계 순서 확인

`Workflow Progress Tracking` 섹션의 line 194 "유효한 단계" 목록을 확인:
- 현재: `discover, create, init, start, plan, design, impl, test, review, merge, pr, done`
- 이미 `discover`, `create`가 포함되어 있음 → **추가 수정 불필요** (Surgical Changes 원칙)

### 4. `.claude-plugin/plugin.json` version bump

`0.17.5` → `0.17.6` (CLAUDE.md 변경에 따른 패치 버전 증가).
