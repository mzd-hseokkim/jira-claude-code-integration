### Warnings
- `scripts/analyze-review-log.py:240` — `aggregate()`가 반환하는 `AggregateResult.skipped`를 항상 0으로 채우고, `main()`에서 `_replace`로 다시 덮어쓰는 패턴은 NamedTuple의 의미를 흐린다. `iter_entries`가 mutable list(`skipped_out`)에 카운트를 누적해 외부에서 주입하는 구조도 일반적이지 않다. 한 가지 단순화: `iter_entries`를 generator class 또는 closure로 만들고 `aggregate`가 fold 결과로 `skipped`를 직접 받게 하거나, `main`이 `format_report`에 skipped를 별도 인자로 전달하므로 `AggregateResult`의 `skipped` 필드 자체를 제거. 현재 구조는 동작하나 향후 유지보수 시 헷갈릴 여지.
- `scripts/analyze-review-log.py:307` — `main(argv: list | None = None)`은 PEP 604 union 문법으로 Python 3.10+를 요구한다. AC-3(크로스 플랫폼)는 OS만 명시하고 Python 버전을 못박지 않았으나, 시스템 Python이 3.9 이하인 환경(예: 일부 macOS 기본/구 Linux 배포)에서 즉시 SyntaxError. plan에 최소 Python 버전을 명시하거나 `from __future__ import annotations`를 추가해 호환 범위를 넓히는 것을 권장. (`aggregate(...) -> ... since: datetime | None`도 같은 사유, line 182.)
- `scripts/analyze-review-log.py:316` — `if not args.input.exists()` 사후 검증이 `iter_entries`의 `FileNotFoundError` 처리(line 136-138)와 중복된다. `parser.error`(exit 2) vs `sys.exit(2)` 두 경로가 모두 살아 있어 의미는 같지만 dead path 발생. 한 곳으로 통일 권장.
- `tests/test_analyze_review_log.py:293` — `import argparse`를 파일 끝에 두고 모듈 상단(`TestU4`, `TestParseSince`)에서 미리 참조한다. 동작은 하지만(클래스 메서드 내 사용은 호출 시점에 평가) PEP 8 위반이며 정적 분석기에 거짓 양성을 유발. 상단 import 블록으로 이동 권장.
