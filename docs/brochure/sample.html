Features

Everything your LLM stack needs

From startup to enterprise scale — the Gateway grows with you.

🔒

Zero-Exposure Key Security

Provider API keys are encrypted with AES-256-GCM and never leave the Gateway. Clients see only virtual keys — Provider credentials stay hidden.

💰

Cost Control & Chargeback

Per-team soft/hard budgets, real-time cost tracking, and automated chargeback reports. Know exactly where every dollar goes.

⚡

Exact-Match Caching

Redis-backed exact-match caching for temperature=0 requests. Identical prompts skip the model entirely — instant response, zero cost.

🛡️

Guardrails & PII Protection

Block prompt injections, mask PII before it reaches any model, and enforce content policies — at the gateway layer, before any token is spent.

🔄

Failover & Circuit Breakers

Automatic provider failover with weighted load balancing. Circuit breakers isolate failing providers so your service stays up.

📊

Full Observability

OpenTelemetry tracing, Prometheus metrics, Langfuse export, immutable audit logs with GDPR/HIPAA retention, and Slack/email alerting.

🔀

OpenAI + Anthropic Native

Serve both the OpenAI API (chat, responses, embeddings) and the Anthropic Messages API natively. Point either SDK at one base_url — no rewrites.

🧠

Intelligent ML Routing

A learned classifier scores cost vs. quality per request and picks the optimal provider. Run A/B tests and promote the winner automatically.

🌍

Data Residency & MCP

Enforce GDPR/HIPAA region routing, and run a central Model Context Protocol hub (stdio, WebSocket, SSE) — all from one self-hosted gateway.
