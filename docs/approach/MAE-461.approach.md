- **Level**: L1 (Single)
- **Source**: N/A — discover 생략, Jira 이슈 설명 기반

## Approach (L1 Single)

- **변경 영역**: `docs/jira-cli.md` "자격증명" 절의 config 명령 표 아래에 `### 예시` 소절 하나를 추가한다 (다른 파일 변경 없음).
- **핵심 결정**: 별도 최상위 절을 만드는 대신 "자격증명" 절 하위 소절로 넣는다 — 문서 목차 구조를 유지하면서 `config show` 설명과 붙여 읽히게 하려는 것. 토큰은 실제 값 대신 표에 이미 쓰인 `ATAT…5AA9` 마스킹 형태만 노출한다.
- **검증**: 소절 존재와 `ATAT…` 마스킹 예시 포함 여부를 grep으로 확인하고 `npm test` 통과를 확인한다.
- **리스크**: 없음 — 문서 한 파일 추가라 실행 경로에 영향이 없다. 실제 토큰 문자열이 섞여 들어가지 않는지만 확인하면 된다.
- **롤백**: 단일 파일 diff이므로 `git revert` 한 번으로 원복된다.
