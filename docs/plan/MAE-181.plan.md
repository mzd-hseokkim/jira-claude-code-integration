# Plan: MAE-181 - [Story 3] 분석 스크립트 scripts/analyze-review-log.py

## Background

Epic MAE-178의 Story 3. 선행 스토리(MAE-179 로그 스키마 정의, MAE-180 review 스킬 append 통합)가 완료된 상태에서, 누적된 `_index.jsonl` 로그를 분석하는 표준 라이브러리 전용 Python 스크립트를 구현한다.

스크립트는 누적 review 통계(누적 횟수, severity 분포, category 빈도 Top N, FP 비율)를 출력한다. 외부 의존성을 도입하지 않아 별도 설치 단계 없이 어떤 환경에서도 즉시 실행 가능해야 한다.

## Acceptance Criteria

### AC-1: stdlib만 사용
- Given: `scripts/analyze-review-log.py`가 작성됨
- When: `python scripts/analyze-review-log.py --help` 실행
- Then: 외부 패키지 import가 0개이고, 정상 실행됨 (`json`, `pathlib`, `argparse`, `collections`, `datetime` 등만 import)

### AC-2: 성능 — 1000건 5초 이내
- Given: 1000건의 entry를 가진 fixture `_index.jsonl`
- When: `time python scripts/analyze-review-log.py --input <fixture>` 실행
- Then: real time이 5초 이내이고 결과가 정상 출력됨

### AC-3: 크로스 플랫폼
- Given: 동일 스크립트
- When: macOS/Linux/Windows에서 실행 (경로 구분자, CRLF/LF, UTF-8)
- Then: 어떤 환경에서도 동일 출력. 경로는 `pathlib.Path` 사용, 파일은 `encoding="utf-8"` 명시

### AC-4: CLI 인자
- Given: 스크립트 실행
- When: `--top 5`, `--since 2026-01-01` 인자 전달
- Then: category Top 5만 출력되고, 해당 일자 이후 entry만 집계 대상이 됨. 둘 다 생략 시 합리적 기본값(top=10, since=없음) 적용

### AC-5: 출력 항목 4종
- Given: 정상 입력
- When: 스크립트 실행
- Then: 출력에 (a) 누적 review 횟수, (b) severity별 finding 분포, (c) category Top N, (d) FP 비율(0.0%)이 모두 포함됨

### AC-6: 사용 예시 + 벤치 결과 기록
- Given: 작업 완료
- When: 스크립트 docstring/모듈 헤더 확인 + 벤치 결과 위치 확인
- Then: 사용 예시 명령이 docstring에 포함되고, 1000건 벤치 결과(real time)가 commit 메시지 또는 design/test 문서에 기록됨

## Scope Decisions

| # | 결정 | 대안 | 선택 이유 | 영향 |
|---|---|---|---|---|
| 1 | FP 비율은 현 단계 항상 0.0% 출력 | 실제 분류 로직 도입 | AC가 "현 단계 0%" 명시. 스키마(MAE-179)에 분류 정보 부재 | 후속 사이클 확장 여지 |
| 2 | fixture는 본 작업에서 자체 생성 | 별도 task로 분리 | 벤치 자체가 AC라 분리 시 검증 불가 | Sub-task 3.3에 통합 |
| 3 | 출력은 plain text (stdout) | JSON 출력 옵션 추가 | AC가 plain 출력만 요구. 추가는 over-engineering | 추후 `--json` 옵션 후보로 보류 |
| 4 | `--input` 기본값 = `_index.jsonl` | 필수 인자화 | 동일 디렉터리에서 즉시 실행 가능 (UX) | 환경별 경로 차이 시 명시 필요 |
