# Plan: MAE-121 - [1.1.8] README 워크플로 다이어그램 갱신

## Background

README의 워크플로 다이어그램(Mermaid `graph LR`)에 `discover` 단계가 누락되어 있다. Phase 1.1 작업(MAE-115~119)으로 `/jira-task discover` 액션이 도입되었으므로, README의 워크플로 시각화를 갱신해 사용자가 신규 단계를 인지할 수 있도록 한다.

선행 의존(MAE-116, 117, 118, 119)은 모두 완료 상태.

## Scope

### In Scope
- README.md `## Workflow` 섹션의 Mermaid 다이어그램에 `discover` 노드 추가 (`create` 앞 단계)
- `discover`의 역할 / 산출물 한 줄 설명 추가
- 한국어 요약 섹션(`## 한국어 요약`)의 핵심 특징 목록에 `discover` 항목 한 줄 추가 (영문/한글 일관성)

### Out of Scope
- discover 스킬 동작 변경
- 워크플로 다이어그램 외 README 구조 리팩터링
- 다른 명령(create, init 등) 설명 갱신

## Acceptance Criteria

### AC-1: 워크플로 다이어그램에 discover 추가
- Given: README의 `## Workflow` Mermaid 블록
- When: 사용자가 README를 읽음
- Then: `/jira-task discover` 노드가 `create` 노드 앞에 표시되고, 둘 사이에 화살표(점선 또는 실선)로 연결된 흐름이 보인다

### AC-2: discover 역할/산출물 한 줄 설명
- Given: 다이어그램 직후 또는 노드 라벨
- When: 사용자가 노드 또는 인접 텍스트를 확인
- Then: discover의 역할(자연어 주제 → 요구사항 문서)과 산출물(`docs/requirements/<slug>.requirements.md`)이 한 줄로 명시된다

## Task Breakdown

| # | Task | Verification |
|---|------|-------------|
| 1 | Mermaid 다이어그램에 `D0["/jira-task discover\n주제 → requirements doc"] -.-> N` 형태로 노드 추가 | README 렌더링 시 discover 노드가 create 앞에 표시 |
| 2 | 다이어그램 아래 부연 설명 한 줄 추가 (또는 노드 라벨에 포함) | 산출물 경로(`docs/requirements/...`)가 명시됨 |
| 3 | 한국어 요약 섹션 핵심 특징 목록에 discover 항목 추가 | 영문/한글 양쪽에 discover 노출 |

## Risks

| Risk | Impact | Mitigation |
|------|--------|------------|
| Mermaid 노드 ID 충돌 (기존 N, A, B...) | 다이어그램 렌더 깨짐 | 새 노드 ID는 `D0` 등 충돌 없는 식별자 사용 |
| 라벨이 너무 길어 다이어그램 가독성 저하 | UX 저하 | 노드 라벨은 2줄 이내 유지, 상세는 본문 한 줄로 분리 |

## Edge Cases

- discover는 선택적 단계(자연어 주제가 명확한 경우 생략 가능) → 화살표를 점선(`-.->`)으로 표기해 "선택" 의미 전달
- discover → create 외에 discover가 직접 init으로 가는 경로는 현재 워크플로상 없음 → 단일 경로만 표기
